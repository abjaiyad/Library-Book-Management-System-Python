# 📚 Library Book Management System — Python

A simple command-line library management system built with Python. It uses a dictionary and a menu-driven interface to manage books.

## ✨ Features

- Add books
- Search books
- Remove books
- Display all books
- Prevent duplicate entries
- Continuous menu until exit

## 🛠️ Concepts Used

- Python 3
- Dictionaries
- `while` loops
- Conditional statements
- User input/output
- Basic CRUD concepts

```bash
git clone https://github.com/abjaiyad/Library-Book-Management-System-Python.git
cd Library-Book-Management-System-Python

```
