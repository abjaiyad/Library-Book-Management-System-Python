# 📚 Library Book Management System

A simple **Library Book Management System** built using **Python**. This project allows users to manage library books through a menu-driven interface.

## 🚀 Features

* ➕ Add new books
* 🔍 Search for books by name
* ❌ Remove books from the library
* 📖 Display all available books
* 🛡️ Prevent duplicate book entries
* 🔄 Continuous menu-driven execution until exit

---

## 🛠️ Technologies Used

* Python 3
* Dictionary Data Structure
* Loops (`while`)
* Conditional Statements (`if-elif-else`)
* CRUD Operations
